# ADR 0008：删除模拟 agent 运行模式

- 日期：2026-11-02
- 状态：已接受并实现
- 依据：用户要求“把模拟 agent 删了，这个模式至少不应该是默认模式”。

## 决定

删除模拟 agent 实现、关键词路由和模拟专用运行分支。应用始终使用原生 CLI 适配器；CLI 不可用或认证失败时显示实际错误。

删除 npm 的 demo 脚本、模拟参数及对应的无界面执行分支。旧参数明确拒绝，避免旧启动命令产生意外真实调用。README 首个启动示例直接使用已验证的 Codex 配置。

测试套件中的协议夹具仅用于自动化验证，不接入应用运行入口。真实联调继续通过 `scripts/live-integration.js` 在隔离 Git 仓库中调用实际 CLI。
