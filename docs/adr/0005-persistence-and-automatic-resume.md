# ADR 0005：保留记录和工作区，重开后自动恢复未完成任务

- 日期：2026-11-02
- 状态：已接受
- 依据：用户对 Q06 选择“保留记录和工作区，重开后自动恢复未完成任务”。

## 决定

退出 TUI 时停止系统执行，但保留记录和 worker 工作区。再次启动时自动恢复未完成任务，不要求用户逐项选择恢复。

## 影响

- 运行状态不能只保存在内存，需要持久化任务、会话关联、工作区关联和恢复所需的执行进度。具体存储结构待设计。
- 恢复未完成任务不等于重新执行全部任务；已完成步骤、已处理结果和提交或集成的实际状态需要核对。
- 进程已经随 TUI 退出停止，恢复需基于各 CLI 的会话继续能力或其他明确的恢复方案。
- 退出不能自动删除仍需恢复的 worktree。

## 尚未确定

记录保留期限、原会话不能恢复时的降级策略、异常崩溃后的恢复流程、处于验收或集成中间状态的恢复规则、以及用户主动暂停或取消的任务是否属于自动恢复范围。
