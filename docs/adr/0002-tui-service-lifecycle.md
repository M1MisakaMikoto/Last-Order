# ADR 0002：服务随 TUI 启停

- 日期：2026-11-02
- 状态：已接受
- 依据：用户明确选择“服务随 TUI 启停，关闭界面就停止整个系统”。

## 决定

schedule_table_service 的生命周期与 TUI 绑定。退出 TUI 时，服务、manager 和 worker 停止执行。首版不将“关闭 TUI 后任务继续在后台执行”作为目标行为。

## 影响

- 正常退出需要收敛管理中的 agent 进程并停止中央服务。
- 必须设计异常退出后的进程回收方式，避免遗留继续执行的 worker。
- “停止执行”与“删除历史记录、代码或 worktree”是不同动作；后续用户已确认保留记录和工作区，并在重开后自动恢复未完成任务，见 ADR 0005。
- 服务独立进程或嵌入应用的技术选择尚未确定，不能从生命周期绑定推导为同一进程。

## 后续问题

退出时是否先请求 agent 安全停止、等待多久、如何终止进程树；历史保存和未完成任务恢复见 ADR 0005。异常崩溃处理和多 TUI 实例策略尚未确定。
