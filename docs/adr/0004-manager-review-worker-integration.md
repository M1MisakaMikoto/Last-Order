# ADR 0004：manager 验收，worker 实现和集成

- 日期：2026-11-02
- 状态：部分被 ADR 0006 更新；worker 负责实现和集成的决定仍有效
- 依据：用户对 Q04、Q05 的明确答复。

## 决定

以下为第二轮答复时的权限定义。第三轮用户进一步明确验收执行也交给 worker，当前职责以 ADR 0006 为准。

manager 可以读取代码、查看 diff、运行验收测试；不得自行修改代码或执行合并。具体实现和合并由 worker 执行。

需要汇总改动时，manager 委派一个 worker 负责集成、解决冲突和验证。manager 继续根据用户需求执行初步验收并对用户汇报。

## 影响

- 集成是可跟踪、可汇报的 worker 工作，不能由 manager 通过直接执行 Git 写操作代替。
- 运行测试可能产生缓存、构建结果或临时文件；需在权限设计中区分这些副作用与修改实现代码。
- 权限边界应在工具和运行层落实，具体机制尚未确定。

## 尚未确定

何时提交、是否新建集成 worker、集成后的复验方式。后续 Q15 已确认汇总到需求交付分支，由用户决定何时合入原工作分支；验收执行职责更新见 ADR 0006。
